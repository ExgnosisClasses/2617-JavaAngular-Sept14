# Course Introduction

## Logistics

- The daily sessions run from 9:00am to 5:00pm Eastern Time
- The last hour of each day is going to be reserved for lab work, Q&A or tangential topics
- There is a one-hour lunch form noon until 1:00pm
  - This hour is sacrosanct - it will not be changed at any point
  - This is so you can schedule meetings, return phone calls or whatever else you need ot do outside class
  - Please try to avoid scheduling anything else during class hours unless absolutely unavoidable
- There will be 15-minute break mid-morning-ish and mid-afternoon-ish
  - The actual time we break will depend on the flow of the material
- Attendance will be taken randomly several times each day
  - If you are going to be away at anytime during the class, please inform the instructor in advance
